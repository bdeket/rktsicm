6 Solve🔗

 (require sicm/solve) package: rktsicm

sicm/solve provides utilities to solve some basic system of equations.

Example:
> (solve-equations
   (list (make-equation '(-  3 (+ x y))  (list 'A))
         (make-equation '(-  5 (- x y))  (list 'B))
         (make-equation '(-  3 (+ (* (sqrt x) z) (square y)))  (list 'C)))
   '(x y z))

(list

 'full-solutions

 (solution '() '() '(((= x 4) (A B)) ((= y -1) (A B)) ((= z 1) (A B C))) '()))

procedure

(solve-equations equations unknowns)

 → 
(or/c (list (or/c 'full-solutions 'underdetermined 'parameters-constrained 'tough-equations 'extra-equations)
            solution?)
      (cons 'contradictions (listof equation?)))
  equations : (listof equation?)
  unknowns : (listof symbol?)
Tries to solve a system of equations for all possible solutions. When a solution is found the first symbol is:

  • 'full-solutions

  • 'underdetermined: remaining unknowns (more unknowns than equations).

  • 'parameters-constrained: overdetermined solutions (more equations than unknowns) where the remaining equations can only be 0 depening on some variable/parameter

  • 'contradictions: equations that reduced to non-zero numbers.

procedure

(solve-incremental equations    
  unknowns    
  [succeed    
  fail]) → (or/c (succeed s f) (fail))
  equations : (listof equation)
  unknowns : (listof symbol?)
  succeed : (-> solution? fail any/c) = (λ (x y) x)
  fail : (-> any/c)
   = (-> (cons (or/c 'failed 'contradictions) (listof any/c)))
Tries to solve a system of equations, the first valid solution, if found, is supplied to the succeed continuation. Otherwise the fail continuation is called.

procedure

(simple-solve equations unknowns)

 → (or/c solution? (cons 'failed #f) (cons 'contradictions (listof equations?)))
  equations : strutl?
  unknowns : (listof symbol?)
Tries to solve a system of equations. The equations are provided as a structure (up or down where each element is solved to be n:zero. The first valid solution, if found, will be returned.

Example:
> (simple-solve
   (up '(-  3 (+ x y))
       '(-  5 (- x y))
       '(-  3 (+ (* (sqrt x) z) (square y))))
   '(x y z))

(solution

 '()

 '()

 '(((= z 1) (eq:0 eq:2 eq:1)) ((= y -1) (eq:2 eq:1)) ((= x 4) (eq:2 eq:1)))

 '())

struct

(struct equation (expression justifications variables))

  expression : expression?
  justifications : (listof symbol?)
  variables : (listof symbol?)

procedure

(make-equation expr [just]) → equation?

  expr : expression?
  just : (listof symbol?) = (list (gensym 'eq))
Create a new equation to be used in solve. Equations are only given by an expression, the implied part is that they are equal to n:zero. On creation the justifications should be a list of just one symbol, to help identify the equation. If nothing is provided a new symbol wil be generated. The variables are all variables present in the expression, not just the unknowns.

procedure

(tough-equations sol) → (listof equation)

  sol : solution?
The return structure of a solve. A solution will have residual-equations if there are more equations than unknowns. It will have residual-variables if ther are more unknowns than equations. It might be that there are enough equations defined but that the solver is not able to find correct answers, then the unused equations are found in tough-equations. All valid solutions can be found in the substitutions. For each substitution the justifications that were used are given.
